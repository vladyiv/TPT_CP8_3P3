# КТ № 8. Анализ результатов тестирования для заданного проекта или продукта
## Навигация
- PetstoreService.Tests.NUnit/ — папка с файлами для тестов на NUnit;
- PetstoreService.Tests.XUnit/ — папка с файлами для тестов на xUnit;
- PetstoreService/ — папка с файлами для тестовых классов и репозиториев;
- README.md - файл с основной информацией;
- TestingSolution.slnx - решение проекта;
- analysis.md - файл с таблицами с качественными и количественными оценками;
- answers.md - файл с ответами на контрольные вопросы;
- dog_image.jpg - фото для тестирования эндпоинта с загрузкой изображения;
